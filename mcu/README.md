# STM32 工程入口

4x4 矩阵键盘使用 `PD0~PD3` 行和 `PD4~PD7` 列。数字 `1/2/3` 分别发送 `TRACKCAL 1/2/3`，执行前三问的 FPGA 硬锁相和香橙派视觉静态相位归正；完成状态由 `TRACKDONE <question> <0|1>` 返回，LCD 显示 `QCAL RUN/OK/FAIL`。`A` 执行第四问；数字 `4/5/6` 分别发送 `MEASURE 1/2/3`，选择第五问的测频相位归零、归零后 `+90°`、归零后二倍频；`B` 启动 100 kHz 参考频率校准。板载 `KEY3/PE2` 保留为第五问任务 1 的兼容入口。STM32 经 USART3 (`PB10/PB11`) 与香橙派通信并执行其返回的 FPGA 控制命令；按键本身不直接改写测频挡位，避免与视觉流程竞争。

LCD 的 `FREQ` 行以 `PI` 标记视觉测频结果。构建、烧录和完整流程见仓库根目录 [README](../README.md)。

STM32 与 FPGA 使用协议版本 4：控制帧第 14 字节承载自由运行 DDS 调谐字的高 8 位，合计 40 位；参考校准计数由 FPGA 返回完整的首尾边沿间隔，不再缺少终止边沿的 1 tick。
